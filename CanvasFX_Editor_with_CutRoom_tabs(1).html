Load pack from a link

GitHub blob links are rewritten to raw.githubusercontent.com automatically, and Gist links to their raw form. The host must allow cross-origin requests (CORS) — raw.githubusercontent.com, gist.githubusercontent.com and cdn.jsdelivr.net all do.
You can also drop a link straight onto the stage, append ?pack=<url> to the page address, or paste raw JSON here.
