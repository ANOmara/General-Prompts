🧠 Documentation Assistant Actions

Context-aware

Every action below sends rich schema context (database, table, columns, keys, related tables, existing descriptions) and produces suggestions only — nothing is written to your documentation until you accept it in the proposals table. كل الإجراءات تُنتج اقتراحات فقط — لا شيء يُكتب في وثائقك حتى تقبله.

Tip: select a table in the Documentation tab first — actions use it as context.
